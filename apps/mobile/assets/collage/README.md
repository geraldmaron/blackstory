# Mobile archive collage tiles

Curated, resized subset of the web rights-cleared pool at
`apps/web/public/brand/collage/tiles/` (Commons promotions / entity primary images).

Retained for possible future native atmosphere work. Mobile edition headers no
longer mount a cycling mosaic; entity / Stories / Themes use the official
BlackStory lockup (`Logo` / `EditionBrandHeader`) instead.

Do not invent documentary imagery. When regenerating, sample from the web pool and
resize with `sips -Z 240` (or equivalent) so the native bundle stays small.
