<p>BlackStory ships as one monorepo so public surfaces, private research tools, and
shared libraries stay on the same contracts.</p>
<p>Current live stack (verified 2026-08-28): public web on <strong>Vercel</strong>, product data
and media on <strong>Supabase</strong> <code>blackstory-app</code>

GCS dual-serve, and parked PostGIS are leftover, not the current system of
record. See <a href="./architecture.md">Architecture</a>.</p>

<h2 id="stable-code-prefixes"><a class="heading-anchor" href="#stable-code-prefixes">Stable code prefixes</a></h2>
<p>Package scope is brand-agnostic so a product rename does not rewrite the
monorepo:</p>
<table>
<thead>
<tr>
<th>Layer</th>
<th>Stable value</th>
</tr>
</thead>
<tbody>
<tr>

<td><code>@repo/*</code></td>
</tr>

<td>CSS / tokens</td>
<td><code>ds-*</code> / <code>--ds-*</code></td>
</tr>
<tr>
<td>Env break-glass</td>

</tr>
</tbody>

<code>apps/web/public/brand/</code> role-based paths.</p>
