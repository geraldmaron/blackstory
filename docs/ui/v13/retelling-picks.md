# The retelling's records: shortlist

**Status:** written 2026-11-23 from the live published catalog. Nothing here is chosen. The owner
picks one record for each of scenes 2, 3 and 5; until then the page runs on three **provisional**
picks, marked below and in `apps/web/src/app/front/retelling-picks.ts`.
**Governs:** `docs/ui/DESIGN.md` section 9.7. A pick is fixed for a release and never rotated, so
the opening is the same for a whole class and can be cited.

## How the list was made

Every record was read through the same code the page uses (`doorRecords`, then
`isJourneyEligible`). A record is on this list only if all of these hold:

- **Well evidenced.** Its claim is graded above "Thinly evidenced".
- **Photographed.** It carries a real, rights-cleared photograph (never an artist's rendering).
- **Not harm-adjacent.** It carries no sensitivity flag, no trauma content note, and is not a
  massacre or plantation record (`isQuietRecord`). Two records that pass that rule were left off
  by hand, and the owner may disagree: the Medgar Evers House (its record's summary is his
  assassination in the driveway) and Bruin's Slave Jail.
- **Not a living person.** See the finding below.
- **Scenes 2 and 3:** the record is plainly about one named man or one named woman, **from its
  own published text**. No record was listed by reading a first name. The column "Not a living
  person" quotes the words in the record that settle it.
- **Scene 5:** a place many people made: a church, a school, a district.

4,402 records were read. 81 pass every rule as the code stands (80 places, one school). The
tables draw on those, plus a few that fail only because their one short claim is a label.

## Three findings the owner should know first

1. **No person record can be used.** The catalog has 497 person records and 233 of them have a
   photograph, but none carries a recorded death (`livingStatus` is empty on all 497), and the
   archive treats unknown as living. So every candidate for scenes 2 and 3 is a **place** record
   that is about a person: a house, a home, a farm. The photograph is of the building, not of the
   person. Showing a portrait in these scenes needs `livingStatus: 'deceased'` set, in review,
   on the person records the owner wants to be eligible.
2. **The page shows the claim the code picks, not one chosen by hand.** `doorClaimFor` takes the
   record's strongest short claim that reads as a whole sentence. For some good records that is
   a weak sentence, and for others the only short claim is a label ("Significant for: Black
   heritage and education"), which keeps the record off the page entirely. Those are marked
   "Needs a pinned claim". Pinning a claim by id is not built; it would be one optional field on
   a pick.
3. **Decade means "first documented in the archive"**, the earliest decade on the record's map
   feature. It is not a founding date, so the page does not print it.

The three sit in the Southeast, the Northeast and the Mid-Atlantic. A final set might put one
west of the Mississippi (the Justina Ford House in Denver or the Samuel Lewis House in Bozeman),
so the camera crosses the country once.

## To change a pick

Edit the record id in `apps/web/src/app/front/retelling-picks.ts` and set `provisional: false`.
The page re-checks the record on every render: if it later loses its photograph, is marked
sensitive, or falls to "Thinly evidenced", its scene shows the word and the sentence with no
exhibit, instead of a record the rules no longer allow.
