# Source library

The staff library extends the existing `story-review` layout, toolbar, notices and disclosure controls. Both themes inherit the kit tokens. Collection guidance and publisher citation usage are separate sections; usage is never a reliability ranking.

Research questions and evidence needs select versioned collection policies through the same service used by CLI, HTTP and MCP. Show the collection, profile review status, version, matching reasons and limits before expandable search methods, provenance and access conditions. Unknown publisher mappings remain explicit. Empty results invite broader and external discovery. Pagination preserves all collection filters.

Keep mobile controls in the existing wrapping toolbar. Disclosures must be keyboard reachable; links retain visible focus. No numerical confidence, trust badges or unsupported completeness claims.
