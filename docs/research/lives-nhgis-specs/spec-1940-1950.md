# Lives Across the Decades — 1940 and 1950 published-table spec (IPUMS NHGIS)

**Scope:** decades 1940 and 1950, conditions population_share, urban, homeownership, high_school,
unemployment, income, farm_tenancy, at **nation and state level only**.

**Method of verification.** Every code below was returned by a live call to
`https://api.ipums.org/metadata/nhgis/...?version=2` on 2026-09-15. Nothing here is inferred from a
naming pattern. The search was exhaustive, not sampled:

- All NHGIS datasets were listed; the complete 1940/1950 universe is six county/state datasets
  (`1940_cPHAE`, `1940_sOcc`, `1940_cAge`, `1950_cPHA`, `1950_sOcc`, `1950_cAge`) plus six
  tract-only datasets (out of scope for nation+state).
- Every data table in all six datasets was fetched individually: **244 tables**, with the full
  `variables[]` list for each.
- Those 244 tables were then scanned for race words (`negro|nonwhite|non-white|white|colored|other
  race|black`), for income words (`income|wage|salary|earning|$`), and for origin words
  (`spanish|hispanic|mexic|puerto|latin|surname`). The scan results are quoted in the GAPS section,
  so a "NOT AVAILABLE" below is a statement about a completed search, not an unfinished one.

**Headline.** Of the 14 (decade, condition) cells, **3 are available** from NHGIS at nation+state:
1940 population_share, 1940 homeownership, 1950 population_share. The other 11 are genuinely not in
NHGIS at this geography and are listed in GAPS with the reason.

**Geography.** All six datasets confirm `geogLevels` including `nation` ("Nation") and `state`
("State"). `1940_cPHAE`, `1940_cAge`, `1950_cPHA` and `1950_cAge` add `county` ("State--County");
`1940_sOcc` and `1950_sOcc` are nation and state only. **No dataset has `breakdowns`** — all six
return `"breakdowns": []` and `"hasMultipleDataTypes": false`, so no `breakdownValues` are needed in
the extract definition. This differs from the 1980–2000 datasets in `decennial.ts`, whose
`LIVES_DECENNIAL_DATASETS[...].breakdownValues` lists are non-empty; for 1940/1950 that list is `[]`.

## 1940

### 1940 · population_share — AVAILABLE

- **Dataset:** `1940_cPHAE` — "1940 Census: Population, Housing, Agriculture & Economic Data
  [US, States & Counties]"
- **Table:** `NT6` · **nhgisCode prefix:** `BYA`
- **Description:** `Race/Nativity`
- **Universe (exact):** `Persons`
- **geogLevels confirmed:** nation, state (also county)
- **breakdownValues:** none — dataset has no breakdowns
- **Race concept crossed:** `Negro` (not "Nonwhite"). White is split by nativity and must be summed.
- **Variables (exact codes and description strings):**

| role | code | description |
|---|---|---|
| Black | `BYA003` | `Negro` |
| white (native) | `BYA001` | `White: Native-born` |
| white (foreign) | `BYA002` | `White: Foreign-born` |
| residual | `BYA004` | `Other` |

- **Denominator / base:** the four `BYA` cells are an exhaustive partition of `Persons`, so the base
  is `BYA001+BYA002+BYA003+BYA004`. Cross-check against `1940_cPHAE NT1` (`BV7`), universe `Persons`,
  variable `BV7001` = `Total`. Request `NT1` alongside `NT6` so the loader can assert the sum.
- **Alternate, same decade, if a sex split is wanted:** `1940_cAge NT6` (`BV2`), universe `Persons`,
  cells `BV2001 White >> Male`, `BV2002 White >> Female`, `BV2003 Negro >> Male`,
  `BV2004 Negro >> Female`, `BV2005 Other >> Male`, `BV2006 Other >> Female`. Note `BV2` does **not**
  split white by nativity, so `BV2001+BV2002` is the whole white population in one step.
- **Definitional trap:** white here **includes** people later counted as Hispanic, exactly as the
  1870–1960 row of the methodology table says. The `white` slice for 1940 must not be labeled
  `white_nh`; use a `white` slice and let the decade note carry the definition.

### 1940 · homeownership — AVAILABLE

- **Dataset:** `1940_cPHAE` — "1940 Census: Population, Housing, Agriculture & Economic Data
  [US, States & Counties]"
- **Table:** `NT49` · **nhgisCode prefix:** `BXX`
- **Description:** `Occupied Dwelling Units by Tenancy Status by Race of Occupants`
- **Universe (exact):** `Occupied Dwelling Units`
- **geogLevels confirmed:** nation, state (also county)
- **breakdownValues:** none
- **Race concept crossed:** `Negro`, with `Other non-white` published separately. This is a true
  Negro cell, not a Nonwhite cell — `BXX002 + BXX003` would be nonwhite.
- **Variables (exact codes and description strings):**

| role | code | description |
|---|---|---|
| Black owner | `BXX002` | `Owner >> Negro` |
| Black renter | `BXX005` | `Tenant >> Negro` |
| white owner | `BXX001` | `Owner >> White` |
| white renter | `BXX004` | `Tenant >> White` |
| other owner | `BXX003` | `Owner >> Other non-white` |
| other renter | `BXX006` | `Tenant >> Other non-white` |

- **Denominator / base:** per group, owner + renter for that group
  (Black: `BXX002+BXX005`; white: `BXX001+BXX004`). All six cells sum to `Occupied Dwelling Units`;
  cross-check against `1940_cPHAE NT44` (`BXS`), universe `Occupied Dwelling Units`, variable
  `BXS001` = `Total`, and against `1940_cPHAE NT45` (`BXT`), universe `Occupied Dwelling Units`,
  cells `BXT001 White`, `BXT002 Negro`, `BXT003 Other non-white`.
- **Definitional traps — two, both load-bearing:**
  1. **The tenure words are `Owner` and `Tenant`, not `Owner occupied` and `Renter occupied`.** The
     existing `decennial.ts` tenure branch derives `tenureOf(cell)` and compares it to the literal
     strings `'owner occupied'` and `'renter occupied'`; on `BXX` every cell would fail that test and
     the loader would throw `"lacks owner or renter cells"`. The 1940 vocabulary has to be added to
     that matcher. (For contrast, the tract-only `1940_tPH_Major NT28` (`BU3`) publishes the *same*
     six cells as `Owner occupied >> White` … `Tenant occupied >> Other non-white`. The state-level
     table does not use those words.)
  2. **It is race of *occupants*, not race of head of household.** The published title is "by Race of
     Occupants". The 1980–2000 tables the project already loads are race *of householder*. That is a
     real definitional break across decades and belongs in the decade's count note, not silently in a
     trend line.

### 1940 · urban — NOT AVAILABLE

`1940_cPHAE NT2` (`BW1`), universe `Urban Persons`, has exactly one variable, `BW1001` = `Total`.
`1940_cPHAE NT41` (`BXP`) is the identical table under a second code (`BXP001` = `Total`).

### 1940 · high_school — NOT AVAILABLE. **No race-crossed equivalent exists.**

Stating this plainly, as asked. `1940_cPHAE NT15B` (`BWW`), universe `Persons 25 Years and Over`, is
sex × attainment only:

```
BWW001 Male >> No years              BWW010 Female >> No years
BWW002 Male >> 1 to 4 years of grade school    BWW011 Female >> 1 to 4 years of grade school
BWW003 Male >> 5 or 6 years of grade school    BWW012 Female >> 5 or 6 years of grade school
BWW004 Male >> 7 or 8 years or grade school    BWW013 Female >> 7 or 8 years or grade school
BWW005 Male >> 1 to 3 years of high school     BWW014 Female >> 1 to 3 years of high school
BWW006 Male >> Four years of high school       BWW015 Female >> Four years of high school
BWW007 Male >> 1 to 3 years of college         BWW016 Female >> 1 to 3 years of college
BWW008 Male >> Four or more years of college   BWW017 Female >> Four or more years of college
BWW009 Male >> Not reported                    BWW018 Female >> Not reported
```

There is **no** race-crossed counterpart anywhere in NHGIS 1940 at nation or state. The complete
list of 1940 tables carrying any race-worded variable, across all three datasets, is:

`1940_cAge NT5A` (BV0, under-1 by race by sex), `NT5B` (BV1, race by sex by age), `NT6` (BV2, race by
sex), `NT7` (BV3, 21+ by race by sex); `1940_cPHAE NT6` (BYA, race/nativity), `NT45` (BXT, dwelling
units by race of occupant), `NT49` (BXX, tenancy by race), `NT80` (BYV, nonwhite 21+ by race by sex),
`NT87` (BY2, farms by race of operator), `NT89` (BY4, land in farms by race of operator), `NT91`
(BY7, value of farmland by race of operator), `NT121` (BWP, 1937 unemployment registration by race by
sex).

None of those twelve is educational attainment. The only remaining 1940 education tables are
`NT13` (BWT, population 5+ by age), `NT14` (BWU, 5+ attending school by age), `NT15A` (BWV, 25+ by
sex), and `NT79` (BYT, median school years completed by sex — `BYT001 Median school years completed
>> Male`, `BYT002 … >> Female`), all unracialized. The base itself is available unracialized
(`BWV001`/`BWV002`), but a base without a numerator is not a figure.

Filling this cell requires transcription from the printed 1940 volumes. Do not substitute the
unracialized `BWW` figures for a Black or white figure.

### 1940 · unemployment — NOT AVAILABLE

The 1940 census "seeking work" tables are published without race:

- `1940_cPHAE NT29` (`BXC`), universe `Persons 14 Years and Over Unemployed/Seeking work` —
  `BXC001 Male`, `BXC002 Female`.
- `1940_cPHAE NT30` (`BXE`), same universe — `BXE001 Experienced >> Male`,
  `BXE002 Experienced >> Female`, `BXE003 New worker >> Male`, `BXE004 New worker >> Female`.
- Labor-force base `1940_cPHAE NT25` (`BW7`), universe `Persons 14 Years and Over in Labor Force` —
  `BW7001 Male`, `BW7002 Female`. Also unracialized.

**Do not use `1940_cPHAE NT121` as the 1940 unemployment figure.** It is race-crossed —
`BWP001 Totally unemployed >> White >> Male` … `BWP012 Partly unemployed >> Negro >> Female` — but
its description is `Unemployed Population by Unemployment Registration by Race by Sex, **1937**` and
its universe is `Unemployed Persons **Registered**`. That is the 1937 Census of Partial Employment,
Unemployment and Occupations, a *voluntary postcard registration* three years earlier, with its own
universe, its own year and no labor-force denominator in NHGIS (`NT120` (BWO) and `NT122` (BWQ) are
the same registration by status and by farm/nonfarm residence). Reporting it as a 1940 unemployment
rate by race would be a category error in year, universe and denominator at once.

### 1940 · income — NOT AVAILABLE

**There is no income table of any kind in NHGIS for 1940 at nation or state level.** 1940 was the
first census to ask wage or salary income, but NHGIS did not digitize the published wage-and-salary
distributions for these geographies. The income-word scan over all 244 tables returned, for 1940,
only:

- `1940_cPHAE NT19` (`BW0`), universe `Manufacturing Establishments` — `BW0001 Annual average wage
  earners in manufacturing, 1939` (an establishment count, not a person's income).
- `1940_cPHAE NT20` (`BW2`), universe `Manufacturing Establishments` — `BW2001 Wages paid in
  manufacturing, 1939` (an aggregate payroll dollar figure).
- `1940_cPHAE NT28A` (`BXA`), universe `Employed Persons 14 Years and Over` — class of worker
  (`BXA001 Wage and salary >> Male` …). "Wage and salary" here is an employment *class*, not an
  income amount.

No brackets, no median, no race. Not available. The `wage_income` class regime the methodology
assigns to the 1940s cannot be built from NHGIS.

### 1940 · farm_tenancy — NOT AVAILABLE (race and tenure are published, but never crossed)

Both halves exist separately and neither can be combined:

- **Race of operator, no tenure:** `1940_cPHAE NT87` (`BY2`), universe `Farms` — `BY2001 White`,
  `BY2002 Non-white`. **Note the concept is `Non-white`, not `Negro`.**
- **Tenure of operator, no race:** `1940_cPHAE NT92` (`BY8`), universe `Farms` — `BY8001 Full owner`,
  `BY8002 Part owner`, `BY8003 Manager`, `BY8004 Tenant`.
- **Tenant type, no race:** `1940_cPHAE NT93` (`BY9`), universe `Farms Operated by Tenants` —
  `BY9001 Cash tenants`, `BY9002 Share-cash tenants`, `BY9003 Share tenants and croppers`,
  `BY9004 Other tenants`. Sharecroppers are inside `BY9003` and are not separately published in 1940.
- **All-operator base:** `1940_cPHAE NT86` (`BY1`), universe `Farms` — `BY1001 Total`.

The remaining race-of-operator tables (`NT89` (BY4) land in farms, `NT91` (BY7) value of farmland and
buildings) are also White/Non-white with no tenure. Every tenure-crossed table in 1940 — `NT94`
(BZA), `NT95` (BZB), `NT96` (BZC), `NT98` (BZE), `NT99` (BZF), `NT100` (BV9), `NT101` (BWA), `NT102`
(BWB), `NT105`–`NT108` (BWE/BWF/BWG/BWH) — crosses tenure with land, value or cropland, never with
race. **Tenant share by race is not available and must not be approximated from the marginals.**

## 1950

### 1950 · population_share — AVAILABLE

- **Dataset:** `1950_cPHA` — "1950 Census: Population, Housing & Agriculture Data
  [US, States & Counties]"
- **Table:** `NT6` · **nhgisCode prefix:** `B3P`
- **Description:** `Sex by Race/Nativity`
- **Universe (exact):** `Persons`
- **geogLevels confirmed:** nation, state (also county)
- **breakdownValues:** none
- **Race concept crossed:** `Negro` (not "Nonwhite"). **This is the only 1950 table at nation or
  state level that separates Negro from Other** — see the trap below.
- **Variables (exact codes and description strings):**

| role | code | description |
|---|---|---|
| Black | `B3P003` | `Male >> Negro` |
| Black | `B3P007` | `Female >> Negro` |
| white (native) | `B3P001` | `Male >> White: Native-born` |
| white (foreign) | `B3P002` | `Male >> White: Foreign-born` |
| white (native) | `B3P005` | `Female >> White: Native-born` |
| white (foreign) | `B3P006` | `Female >> White: Foreign-born` |
| residual | `B3P004` | `Male >> Other` |
| residual | `B3P008` | `Female >> Other` |

- **Denominator / base:** all eight `B3P` cells (an exhaustive partition of `Persons`). Cross-check
  against `1950_cPHA NT1` (`B18`), universe `Persons`, variable `B18001` = `Total`.
- **Definitional trap — the Negro/Nonwhite split.** `B3P` is the exception, not the rule. Every other
  1950 race table at this geography publishes only **White / Non-white**, and those two categories
  are *not* interchangeable with White / Negro:
  - `1950_cAge NT15` (`B1T`), universe `Persons` — `B1T001 White`, `B1T002 Non-white`
  - `1950_cAge NT20` (`B1Z`), universe `Persons` — `B1Z001 White >> Male` … `B1Z004 Non-white >> Female`
  - `1950_cAge NT16` (`B1U`), universe `Persons 21 Years and Over` — `B1U001 White`, `B1U002 Non-white`
  - `1950_cAge NT21` (`B10`), universe `Persons 21 Years and Over` — `B10001 White >> Male` … `B10004 Non-white >> Female`
  - `1950_cAge NT14` (`B1S`) / `NT19` (`B1X`), universe `Persons 75 Years and Over` — same pair
  - `1950_cAge NT12` (`B1Q`), `NT13` (`B1R`), `NT17` (`B1V`), `NT18` (`B1W`) — race by age, race by
    sex by age, all White / Non-white
  - `1950_cPHA NT48` (`B3C`), universe `Non-White Persons 21 Years and Over` — `B3C001 Male`,
    `B3C002 Female`. This is a nonwhite total with **no** Negro cell.
  - `1950_cPHA NT36` (`B2Z`) `Percent Non-White Population to the Nearest Decile` — county level
    only, value ranges, unusable.

  Use `B3P` for the population share and record the slice as Black/Negro. If any future 1950 work
  reaches for a `cAge` race table, the resulting figure is **nonwhite**, which in 1950 includes
  American Indian, Japanese, Chinese and other groups, and must be labeled `nonwhite`, never `black`.
  The ingest code matches on cell text, so a table swapped for convenience will silently change what
  the number means.

### 1950 · homeownership — NOT AVAILABLE. **There is no housing tenure table at all.**

Despite the dataset title "Population, **Housing** & Agriculture Data", `1950_cPHA` contains **no
dwelling-unit table of any kind**. A keyword sweep of all 85 `1950_cPHA` tables for
`dwelling|tenure|tenant|owner|rent|hous` returns only:

- `NT18` (`B2H`) `Married Couples by Household Status`, `NT21` (`B2K`) `Households`
  (`B2K001 Total`), `NT22` (`B2L`) `Population in Households` — households, not housing units, and no
  tenure and no race;
- and fifteen **farm** tenure tables (`NT54`, `NT77`, `NT78A`, `NT78B`, `NT79`, `NT81`–`NT85`,
  `NT87`–`NT90`), which are farm operator tenure, not home ownership.

The "Housing" in the title refers to the household counts. Owner/renter occupied dwelling units by
race of head do not exist in NHGIS 1950 at nation or state. Contrast 1940, where `1940_cPHAE NT49`
(`BXX`) does publish them — the 1940-to-1950 homeownership series simply breaks here.

For the record, NHGIS does carry 1950 tenure by race at **tract level only** and in a degraded form:
`1950_tPH_Major NT30` (`B0V`), universe `Dwelling Units with **Nonwhite** Occupants`, cells
`B0V001 Owner occupied`, `B0V002 Renter occupied`. That is tract-only, nonwhite rather than Negro,
and covers only major cities. It cannot be aggregated to a state and must not be used.

### 1950 · income — NOT AVAILABLE

1950 was the first family-income census, and NHGIS carries **no family income bracket table at
nation or state level, for any race**. The income-word scan over all 244 tables returned, for 1950:

- `1950_cPHA NT39` (`B22`), description `Median Family Income (1949) of Families [Value ranges,

## The Hispanic lens, 1940 and 1950

**Hispanic origin was not separately published in 1940 or 1950 at state level, and no proxy should be
substituted.** All 244 data tables were scanned for `spanish|hispanic|mexic|puerto|latin|surname`.
Exactly two hits came back, and **neither is an origin variable**:

- `1940_cPHAE NT17` (`BWY`), `Foreign-Born White Population by Country of Birth` — `BWY038 Mexico`
- `1950_cPHA NT26` (`B2P`), `White Population by Country of Birth` — `B2P026 Mexico`

Both are **country of birth of the foreign-born white population**. They exclude every US-born person
of Mexican descent, exclude everyone from every other Spanish-speaking country, and exclude anyone
not counted as white. Using either as a Hispanic figure would understate the population by a large
and unknown factor and would misrepresent what the census measured.

There is **no** Spanish-surname variable and **no** Puerto Rican birth or parentage variable anywhere
in NHGIS 1940 or 1950. As the methodology's era table records, Spanish surname (five southwestern
states) and Puerto Rican birth or parentage were published for 1950 only for selected states and
areas, and are not in NHGIS at all. Also note 1930's "Mexican" race category had been **removed** by
1940 — the 1940 race cells are `White` (by nativity), `Negro`, `Other`, with no Mexican cell.

**Every 1940 and 1950 Hispanic cell is `not_measured`**, linked to the decade's count note. Do not
invent a figure, do not interpolate from 1930 or 1960, and do not use the `Mexico` country-of-birth
cells.

### What would need transcription from printed volumes instead of NHGIS

All eleven gap cells above. NHGIS has been searched exhaustively at this geography — including its
`time_series_tables` endpoint, where only two of 400 time series reach 1940 or 1950 (`A00` Total
Population and `A08` Persons by Sex, neither race-crossed) — so these are not findable by a better
query. They are either transcribed from the printed Census Bureau volumes and subject reports or they
stay `not_measured`.

Grouped by what a transcription pass would have to go and find:

1. **Race-crossed educational attainment, 1940 and 1950** (25+, 4 years of high school or more, by
   race, with the 25+ base). Would come from the printed population volumes' state chapters and/or
   the nonwhite/Negro subject reports.
2. **Race-crossed unemployment, 1940 and 1950** (seeking work / unemployed by race, with the
   labor-force base).
3. **1940 wage or salary income by race**, with bracket boundaries and a national median.
4. **1950 family income by race**, with bracket boundaries and a national median. The bracket shape
   to expect is the `B0E001`–`B0E014` ladder quoted above (`Less than $500` through `$10,000 or
   more`), which should be confirmed against the print, not assumed.
5. **Race-crossed farm tenure, 1940 and 1950** (tenants and sharecroppers as a share of operators, by
   race). The Census of Agriculture published color-of-operator × tenure cross-tabulations; NHGIS
   carries only the marginals.
6. **Urban residence by race, 1940 and 1950.**
7. **1950 homeownership by race** — owner/renter occupied dwelling units by race of head, at state
   level, from the 1950 Census of Housing volumes.

**Partial coverage warning for the 1950 transcription work.** The project records a partial-coverage
share alongside a figure, and that mechanism will be needed for most of the 1950 list. Nothing NHGIS
itself carries for 1950 is coverage-restricted — it is restricted by *not existing* — but the printed
1950 nonwhite detail that would fill items 1, 2, 4, 6 and 7 was substantially published only for
areas with 50,000 or more inhabitants. A transcriber must record, per state, which areas the
published table actually covered, and the loader must compute the covered share of the region's group
population against the methodology's 80% withholding floor. Do not assume statewide coverage of any
1950 nonwhite table because a state total appears — check what the table's own headnote says it
covers. Expect several Deep South states to clear the floor and much of the West and Northeast not to.

**Race-concept warning for the same work.** Several printed 1950 nonwhite tables report **Nonwhite**,
not **Negro**. Nonwhite in 1950 includes American Indian, Japanese, Chinese and other groups. Where
only a nonwhite figure can be transcribed, store it with a `nonwhite` slice and its own label — never
as `black` — because the ingest matches on the label text and the surface would otherwise assert a
Black figure the census never published.

## Extract definition for what IS available

Three cells, two datasets, no breakdowns:

```
1940_cPHAE: dataTables NT6 (BYA), NT49 (BXX), NT1 (BV7), NT44 (BXS), NT45 (BXT)
            geogLevels [nation, state]   breakdownValues []
1950_cPHA:  dataTables NT6 (B3P), NT1 (B18)
            geogLevels [nation, state]   breakdownValues []
```

`NT1`/`NT44`/`NT45` are cross-check tables, not figures: they let the loader assert that the race
cells sum to the published total before writing an observation, the same discipline `decennial.ts`
already applies by requiring exactly one `Total` cell per group.

Two loader changes are required before these can be ingested by the existing `decennial.ts` shape:

1. `LivesCensusYear` is currently `1980 | 1990 | 2000`, and `readDecennialFileName` matches
   `/_(1980|1990|2000)_(nation|state)\.csv$/`. Both need 1940 and 1950.
2. The tenure branch compares against the literal strings `'owner occupied'` and `'renter occupied'`.
   1940's `BXX` publishes `Owner` and `Tenant`. Without widening that matcher the 1940 homeownership
   table throws `"lacks owner or renter cells"`.
