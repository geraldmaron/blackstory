# Lives Across the Decades — verified NHGIS table spec, 1910 / 1920 / 1930

Every table code, nhgisCode, universe string and variable code below was returned by a live call to
`https://api.ipums.org/metadata/nhgis/...?version=2` during this pass. Nothing is inferred from a
printed volume or from memory. Where a cell is a gap, the gap is stated with the table that was
checked and found not to carry the crossing.

## Datasets used (all verified live; none has `breakdowns`, so no `breakdownValues` are required)

| dataset | published title (API `description`) | geogLevels |
|---|---|---|
| `1910_cPHA` | 1910 Census \| Population, Housing & Agriculture Data [US, States & Counties] | nation, state, county |
| `1910_sOccFarmer` | 1910 Census \| Occupation Data & Farmer Characteristics [US & States] | nation, state |
| `1910_cAg` | 1910 Census \| Agriculture Data [US, States & Counties] | nation, state, county |
| `1920_cPHAM` | 1920 Census \| Population, Housing, Agriculture & Manufacturing Data [US, States & Counties] | nation, state, county |
| `1920_sOccFarmer` | 1920 Census \| Occupation Data & Farmer Characteristics [US & States] | nation, state |
| `1920_cAg` | 1920 Census \| Agriculture Data [US, States & Counties] | nation, state, county |
| `1930_cPAE` | 1930 Census \| Population, Agriculture & Economic Data [US, States & Counties] | nation, state, county |
| `1930_cFH` | 1930 Census \| Family & Housing Data [US, States & Counties] | nation, state, county |
| `1930_sOcc` | 1930 Census \| Occupation Data [US & States] | nation, state |
| `1930_cAg` | 1930 Census \| Agriculture Data [US, States & Counties] | nation, state, county |
| `1930_cAge30` | 1930 Census \| 1930 Detailed Age Data from 1930 Volumes [US, States & Counties] | nation, state, county |

**`breakdownValues`: none.** All eleven datasets returned `breakdowns: []`. Unlike the 1980–2000
summary-file datasets in `decennial.ts`, the pre-1940 datasets carry no geographic-component or
race breakdown axis — race is inside the variable list, so every cell is found by its variable
`description` text.

**Per-table geography:** the NHGIS `data_tables/{TABLE}` response carries only
`name, description, universe, nhgisCode, sequence, datasetName, variables` — no per-table
`geogLevels`. Availability is the dataset's `geogLevels`, and every dataset above includes both
`nation` and `state`. No tract/ward/ED dataset is used.

**Race label texts, exactly as the API returns them** (these are what ingest must match on):

- 1910 population: `White`, `Negro`
- 1910 / 1920 / 1930 literacy and schooling: `White: Native-born`, `White: Foreign-born`, `Negro`
  (1910 schooling splits native white further — see that section)
- 1920 / 1930 population: `White: Native-born`, `White: Foreign-born`, `Negro`
- 1930 families and housing: `White: Native born`, `White: Foreign born`, `Negro`, `Other`
  (note: **no hyphen** in "Native born" / "Foreign born" here, unlike the population tables)
- farm tables, state-level occupation datasets: `White`, `Colored`
- farm tables, county-capable datasets: `Native-born whites` / `Native White` / `native white`,
  `Foreign-born whites` / `Foreign White` / `foreign-born white`,
  `Negroes and other non-whites` / `Negroes/non-White` / `Negro and other nonwhite` /
  `negro and other non-white` — spelling and case vary by dataset, so match per table, not globally

## 1910 — population_share  ✅ VERIFIED

- dataset: `1910_cPHA` — "1910 Census | Population, Housing & Agriculture Data [US, States & Counties]"
- table: **NT11**, nhgisCode prefix **`A30`**
- description: `Race by Sex`
- universe: `Persons`
- geogLevels confirmed: nation, state (dataset also county)
- breakdownValues: none

Race variables (sum male + female for a group total):

| code | description |
|---|---|
| `A30001` | `White >> Male` |
| `A30002` | `White >> Female` |
| `A30003` | `Negro >> Male` |
| `A30004` | `Negro >> Female` |

Denominator (everyone) — `1910_cPHA` **NT1**, code **`A3Y`**, description `Total Population by Year`,
universe `Persons`:

| code | description |
|---|---|
| `A3Y001` | `1910` |
| `A3Y002` | `1900` |

Supporting totals, same dataset: **NT75** / `A5A` `Total White Population`, universe `White Persons`,
`A5A001 = Total`; **NT7** / `A46` `Total Population of Indians, Chinese, Japanese and Persons of All
Other Races`, universe `Persons of Indian, Chinese, Japanese and Persons of All Other Races`,
`A46001 = Total`.

**Trap:** `A3Y` publishes two census years side by side. `A3Y002` is the **1900** count; using it
silently backdates the denominator by a decade. Also, `A30` carries only White and Negro — it does
not sum to the total population, and the residual is `A46001`, not a race the timeline lenses cover.

## 1910 — urban  ❌ NOT AVAILABLE by race

Checked and found not race-crossed at nation+state:

- `1910_cPHA` **NT2** / `A36` `Total Urban Population`, universe `Urban Persons`: `A36001 = Total`
- `1910_cPHA` **NT5** / `A4V` `Urban-Rural Residence by Reporting Year`, universe `Persons`:
  `A4V001 = Urban (populations residing in places of 2,500 or more persons) >> 1910`,
  `A4V002 = ... >> 1900`, `A4V003 = Rural (populations residing in remainder of county/state) >> 1910`,
  `A4V004 = ... >> 1900`
- `1910_cPHA` **NT6** / `A43` `Urban-Rural Residence`, universe **`Persons in 1900`**:
  `A43001 = Urban (...2,500 or more persons)`, `A43002 = Rural (...)`

Reason for the gap: NHGIS publishes 1910 urban/rural for the total population only. No 1910
nation-or-state table crosses urban residence with race.

**Trap if this is ever filled from elsewhere:** the 1910 variable text names the urban threshold
explicitly ("places of 2,500 or more persons"); the 1920 and 1930 urban variables just say `Urban`
with no threshold in the text. And `A43`'s universe is `Persons in 1900`, not 1910, despite its
neutral description — use `A4V001` for a 1910 urban total, never `A43001`.

| group | illiterate (`A4A`) | base (`A39`) | description text (identical in both) |
|---|---|---|---|
| white, native-born | `A4A001` | `A39001` | `White: Native-born` |

`Race of Farmer`, universe `Farms`: `A5U001 = White`, `A5U002 = Colored`. All-operator base:
**NT11** / `A5E` `Tenure of Farmer`, universe `Farms`: `A5E001 Owner`, `A5E002 Tenant`,

**Sharecropper detail:** **NT22** / `A5R` `Farms Operated by Tenants by Type of Tenant by Race of

**Alternative (also county), different race concept:** `1910_cPHA` **NT65** / `A45` `Farms Operated by
Tenants by Race/Nativity`, universe `Farms Operated by Tenants`: `A45001 White: Native-born`,
`A45002 White: Foreign-born`, `A45003 Negro and other nonwhite`; base **NT49** / `A4U`
`Total Number of Farms by Race/Nativity`, universe `Farms`: `A4U001 White: Native-born`,
`A4U002 White: Foreign-born`, `A4U003 Negro and other nonwhite`. Also `1910_sOccFarmer` **NT5** /
`A5V` (`Native-born whites` / `Foreign-born whites` / `Negroes and other non-whites`), **NT20** / `A5P`

**Trap — race concept:** `Colored` (`A5F`, `A5U`, `A5R`) and `Negro and other nonwhite` (`A45`,

is small, in the West it is not. The `A5F`/`A45` pair also disagree on the white split (one axis vs
two), so the two sources are not interchangeable mid-series. Counting unit is the **farm**, not the
farmer and not the household. 1910 tenure has no "part owner" or "cropper" class — those appear in
1930.
