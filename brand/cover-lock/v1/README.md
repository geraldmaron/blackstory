# House lock v1

This slot is the versioned house lock for article cover plates.

The lock is a **scan of the actual dry felt-tip drawing on cream paper**. It is not a prompt, not a generated image, and not a stock photo.

Design drops the first scan here as `plate.scan.jpg` or `plate.scan.png`.

Cite this lock as `cover-lock/v1` from the admin article form.

House hand (for plates drawn against this lock):

- one hand: dry felt-tip, slightly wobbly, one weight
- paper cream, blue-black ink, one burnt-ochre sliver (never more than a sliver of the frame)
- fills are hatch only; no vector smoothness, watercolor, or drop shadows
- same pen, same paper crop, same four recipes: object-as-metaphor, scene, character, doodle-diagram
